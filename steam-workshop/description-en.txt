[h1]Smooth Zoom Transitions[/h1]

[b]Guide:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3800254441]CK3 on a potato PC: a locked 60 FPS, and the map still looks sharp[/url] — the settings and mods this belongs to.

Removes the two frame hitches you get while zooming the map: the one where the terrain fills up with county colours, and the one where the map flattens out and titles group into empires. Nothing is removed from the game — the work is simply spread out instead of landing in a single frame.

[h2]The cause[/h2]

It is not one expensive system. It is that vanilla schedules almost everything on the [b]same zoom step[/b].

[b]Zoom step 9[/b] is where all twelve of these happen at once:

[list]
[*]the three tree layers unload (tree_low, tree_medium, tree_high)
[*]the activity, building and unit layers unload — every holding model on the map
[*]coast foam and mountain environment effects unload
[*]fort icons hide (FORT_VISIBLE_ZOOM_STEPS = { 0 9 })
[*]raid icons switch size (DETAILED_RAID_SIMPLE_TO_DETAILED_ZOOM_STEP = 9)
[*]map names swap from small to large (LARGE_NAMES_ZOOM_STEP = 9)
[*]the realm colour overlay starts filling (REALM_COLOR_MAP_START_ZOOM_STEP = 9)
[/list]

Every one of those mesh instances is torn down in one frame — and rebuilt in one frame the moment you zoom back in, limited only by MAX_MESHES_LOADED_PER_FRAME = 100.

[b]Zoom step 21[/b] is the same story. FLAT_MAP_ZOOM_STEP = 21 is also where the map table layers fade in, where realm capital icons hide, and where DISABLE_PROVINCE_AND_COUNTY_IN_FLAT_MAP = yes throws the province and county borders away entirely — so zooming back in rebuilds them from scratch.

[h2]The fix[/h2]

[list]
[*]the per-frame mesh loading budget drops from 100 to 50, so streaming is amortised over several frames instead of spiking in one
[*]fort icons, raid icons, map names and the start of the colour overlay all move off step 9
[*]activities unload on step 7 and units on 10 instead of 9; the holding models keep vanilla's step 9, because that is the click on which the realm colours arrive and a painted map has no use for them (1.0.0 took them away on 8, a click before any colour)
[*]coast foam and mountain effects move down to steps 6 and 7
[*]the icon work vanilla puts on steps 20 and 21 moves off the flat map transition
[*]the map name placement search samples less densely — that search is exactly what runs when the visible title tier changes
[*]full border rebuilds run half as often; partial updates are untouched, so borders still follow conquests
[/list]

The tree layers are deliberately left on step 9. That is where players expect forests to disappear, and moving them changes how the whole map reads while zooming. Everything that used to share the step with them moved instead.

[h2]Trade-offs, stated plainly[/h2]

[list]
[*]activities, coast foam and mountain effects disappear one or two steps earlier than you may be used to; army models are kept one step longer; holdings unload where vanilla unloads them
[*]large map names appear at step 11 instead of 9, and the crossfade between small and large names is shorter
[*]the name placement search is coarser, so the occasional name sits slightly differently than in vanilla
[*]the very first zoom out of a session is still slower than the rest: that is the game compiling shader permutations it has not cached yet, and no mod can prevent it
[/list]

[h2]Ultrawide extra[/h2]

NAME_DRAW_DISTANCE is a radius tuned for a 16:9 frustum. On an ultrawide screen far more of the map falls inside it, so the game lays out and draws many more curved map names than it was tuned for — and that layout is exactly what runs at every zoom transition. The mod ships an opt-in file that cuts the radius; see the GitHub readme for how to switch it on.

[h2]Notes[/h2]

[list]
[*]Graphics-only: no gameplay, script or history files are changed, so ironman and achievements are unaffected
[*]Safe to add or remove at any time, including mid-campaign — it does not touch save games
[*]No shaders are touched, so it stacks with shader mods without conflict
[*]Every change is a separate file, so any single group can be tested on its own by removing one file
[*]Works with Advanced Shaders both on and off
[*]Built for CK3 1.19.x
[/list]

[h2]Compatibility[/h2]

The defines files add keys rather than replacing the vanilla defines file, so they only collide with another mod that changes those same keys. Two map object layer files are full replacements and will conflict with any mod that adds or removes map object layers — load this mod before such a mod, or merge the tables by hand.

On [b]A Game of Thrones[/b] this mod needs its patch. AGOT ships its own zoom steps and its own map object layer table, where the holding models stay until step 16 and four AGOT-only layers (special buildings, roads, animals) exist; the table here, loaded below AGOT, unloads the holdings on step 8 - before AGOT's colour overlay even starts - and leaves those four layers undeclared. AGOT Patch for Smooth Zoom Transitions is AGOT's table with the same idea applied to AGOT's numbers; load it below AGOT:
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3801073796]AGOT Patch for Smooth Zoom Transitions[/url]
