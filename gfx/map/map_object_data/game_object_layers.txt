# Vanilla drops activities, buildings and units all on zoom step 9, the same
# step that unloads the three tree layers, the coast foam and the mountain
# env effects, hides the fort icons, swaps the map names and starts the realm
# colour overlay. Everything is torn down in one frame.
#
# These three move off that step:
#
#   layer             vanilla  here   camera height
#   activities_layer        9     7   295
#   building_layer          9    11   513
#   unit_layer              9    10   453
#
# Holdings go on step 11: the realm colour overlay starts filling on 10 (this
# mod moves the start there from 9) but is barely there for a step, and 11
# is where the colours visibly arrive, so the castles and towns leave with
# them instead of two steps earlier. A layer pushed higher stays visible over
# a wider zoom range and the visible map area grows fast as you pull back, so
# this is as far as it goes; the AGOT patch uses 12 on a map with fewer
# holdings. Change the number below if you want to try another step.
