# Overrides game/gfx/map/map_object_data/game_object_layers.txt
#
# Vanilla drops activities, buildings and units all on zoom step 9, the same
# step that unloads the three tree layers, the coast foam and the mountain
# env effects, hides the fort icons, swaps the map names and starts the realm
# colour overlay. Everything is torn down in one frame.
#
# These three move off that step. They move *down*, not up:
#
#   layer             vanilla  here
#   activities_layer        9     7
#   building_layer          9     8
#   unit_layer              9    10
#
# The direction matters. A layer pushed to a higher step stays visible over a
# wider zoom range, and the visible map area grows fast as you pull back - so
# raising building_layer means drawing every holding model on a much larger
# slice of the map than vanilla ever did. An earlier version of this mod used
# 10 / 11 / 12 and cost frame rate exactly while zooming in towards county and
# duchy level. Unloading earlier is free; only unit_layer is raised, because
# armies are worth seeing a step longer and there are few of them.

layer={
	name="activities_layer"
	fade_in=0
	fade_out=7
	category=""
	masks=""
	visibility_tags=""
}
layer={
	name="building_layer"
	fade_in=0
	fade_out=8
	category=""
	masks=""
	visibility_tags=""
}
layer={
	name="unit_layer"
	fade_in=0
	fade_out=10
	category=""
	masks=""
	visibility_tags=""
}
